## Overview Proyek

Proyek ini dibangun untuk menjawab kebutuhan toko ritel skala menengah yang membutuhkan platform e-commerce berkecepatan tinggi tanpa mengorbankan pengalaman pengguna (*user experience*).

Dengan memanfaatkan **Inertia.js**, aplikasi ini menggabungkan ketangguhan ekosistem **Laravel** di bagian *backend* dengan keandalan reaktivitas **React** di bagian *frontend*, tanpa perlu membangun REST API secara terpisah.

---

## Fitur Utama

- **Single Page Application (SPA) Experience:** Perpindahan halaman terasa instan tanpa proses *full page reload*.
- **Manajemen Keranjang Real-time:** Pengelolaan stok dan keranjang belanja menggunakan *state management* React.
- **Integrasi Payment Gateway:** Pembayaran otomatis menggunakan Midtrans API (Bank Transfer, QRIS, & E-Wallet).
- **Dashboard Admin & Analytics:** Laporan penjualan interaktif, manajemen produk, dan status pengiriman barang.
- **Keamanan & Autentikasi:** Sistem autentikasi bertingkat (*Role-based Access Control*) menggunakan Laravel Breeze.

---

## Tantangan & Solusi Teknis

### 1. Performa Render Produk yang Banyak
> **Tantangan:** Halaman katalog mengalami penurunan performa ketika menampilkan ratusan produk sekaligus.  
> **Solusi:** Menerapkan *server-side pagination* dan teknik *lazy loading* gambar, serta memanfaatkan *indexing* pada database MySQL di kolom kategori dan harga.

### 2. Sinkronisasi State antara Laravel & React
> **Tantangan:** Memastikan data keranjang belanja dan status login pengguna selalu tersinkronisasi.  
> **Solusi:** Menggunakan fitur `Shared Data` dari Inertia.js untuk mengirimkan data sesi pengguna langsung ke dalam props *root component* React.

## Kode Pilihan (*Code Snippet*)

Berikut adalah contoh bagaimana data dikirimkan dari Laravel Controller ke komponen React melalui Inertia:

```php
namespace App\Http\Controllers;

use App\Models\Product;
use Inertia\Inertia;
use Inertia\Response;

class ProductController extends Controller
{
    public function index(): Response
    {
        return Inertia::render('Products/Index', [
            'products' => Product::with('category')
                ->where('is_active', true)
                ->latest()
                ->paginate(12)
        ]);
    }
}
